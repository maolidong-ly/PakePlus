西典排课 — Windows 打包用静态资源（PakePlus）
版本：2026-10-20（课时模版修复、预装数据导出、应用模版到课表）

【PakePlus 识别不了文件夹？请看这里】

1) 路径不要有中文 → 解压到 C:\xidian-paike-win\

2) 网站地址：浏览选择 C:\xidian-paike-win\index.html

3) 本地打包，路径全英文

4) 首次打开：创建管理员（仅一次）；之后应显示「登录」
   若仍每次都要创建：请用本 zip 重新打包（旧 exe 不含修复）

5) vendor、audio 文件夹勿删（导出图片 / 菜单音效需要）

6) 预装业务数据（班级/教师/教室/课程/课表/课时模版，不含账号）：
   - 在软件「课表排课 → 备份与恢复」点「导出预装数据（打包用）」
   - 将得到的 bundled_app_data.json 放到本目录（与 index.html 同级），覆盖原文件
   - 再 PakePlus 打包；用户新装后首次打开会自动载入这些数据
   - 若用户电脑上已有 schedule_app_data.json，则不会覆盖，仍以用户本地为准

入口：index.html
